# 浏览器验收

运行命令与依赖见 [运行说明](../../docs/RUNNING.md)。三套脚本依次是 e2e.cjs（20 项）、supplement.cjs（13 项）、ui-polish.cjs（11 项），各用新的外部合成库和输出目录。

真实服务部分覆盖登录、索引任务、版本、三角色权限、跨区访问、成员撤销、最后 owner 保护、拒绝请求前后的数据库指纹。真实 ONNX 模型用于双语搜索，不等于重新运行完整冻结检索集。

浏览器部分通过控制路由或事件验证迟到响应、断网、旧 401、非 JSON 错误、标签页返回和 XSS 文本显示。这些是受控交互模拟，不是实际操作系统切换或真实网络事故，不能替代服务端安全测试。LOCK01 读取内部状态 `state.researchAfterCheck`，属于白盒断言。

ui-polish 还验证欢迎区、权限核验期间的按钮与 inert 锁定、手动修正译文保持 query/language/method、以及命中词通过文本节点高亮。搜索辅助函数等待请求内容匹配的响应和新渲染节点，避免把旧结果当成新结果。

历史首轮 LOCK01 因辅助函数提前读取旧结果而失败；修正等待方式后完整复测通过。原始失败证据留在作者本地，没有覆盖，也不作为公开资料上传。公开版只将机器专属 Python/Playwright 路径改为环境配置，保留测试断言。
